## Execute on a reviewed, immutable same-repo PR head

1. Choose an open `atto-lang/atto-source.forge` PR targeting `main` (e.g. [#207](https://github.com/atto-lang/atto-source.forge/pull/207)). A distinct qualified human reviewer with effective write/maintain/admin permission must submit `APPROVED` explicitly against **that exact head SHA**. No author self-approval, bot approval, stale/dismissed reviews, outstanding change requests, or read-only membership.
2. Independently read GitHub `pulls/<PR_NUMBER>.head.sha` and `git/commits/<HEAD_SHA>.tree.sha`. After the workflow itself is independently reviewed and merged to protected main and the dedicated runner has been provisioned, use **Actions → AttoLang Forge exact-head source-local compiler tests (full CTest) → Run workflow** on `main`; supply `expected_pr_number`, `expected_head_sha`, and `expected_tree_sha`.
3. The source-local workflow checks current PR number, source and base repository ID `1448701874`, exact head SHA/tree, review state and independent reviewer permission before checkout. It runs mocked admission tests from protected `main`; checks out the PR SHA using `persist-credentials:false`; verifies actual commit/tree and clean working tree; and re-runs authorization after tests.
4. Run GCC, Clang and Clang ASan/UBSan complete CMake compiler builds, fail-closed CTest discovery and full CTest execution. Print binary SHA-256, source commit/tree and latest run attempt. Missing critical tests, failed execution, no runner assignment or zero executed steps **must not** be called a pass. Mailbox ThreadSanitizer, fuzz and target-specific AOT checks still need their own evidence.
5. Recheck the exact live PR head, all independent approvals, complete recorded job steps, successful test logs and any newer main changes before promotion or merge. Source-local testing does not substitute for merge-governance review.
